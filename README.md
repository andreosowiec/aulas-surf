# Aulas Particulares de Surf — PDF

Projeto para criação e manutenção da apresentação comercial
do serviço de aulas particulares de surf.

## Estrutura

- `docs/` — informações e briefing
- `assets/` — imagens e recursos visuais
- `src/` — documento fonte
- `dist/` — PDF final

## Documento principal

As regras e valores oficiais estão em:

`docs/service-spec.md`

## Desenvolvimento

O documento é desenvolvido em HTML/CSS e posteriormente exportado
para PDF.

## Objetivo

Produzir um PDF profissional otimizado principalmente para envio
via WhatsApp e visualização em dispositivos móveis.
